# 카페 자동 접속 도구 (Windows 10)

Microsoft Edge가 필요합니다. `cafe-visitor.bat` 파일 하나만 다운로드하고 더블클릭하세요.

1. **로그인 후 자동 접속 시작**: 네이버 로그인 화면이 열립니다. 직접 로그인한 후 카페 접속을 확인하고, 검은 콘솔 창으로 돌아와 Enter를 누르세요. Enter를 누르기 전에는 창을 자동으로 닫지 않습니다.
2. **저장된 로그인 상태로 바로 시작**: 다음 실행부터 선택할 수 있습니다.
3. **로그인만 하고 종료**: 로그인 상태만 저장하고 종료합니다.

로그인 화면의 로그인 상태 유지를 선택하면 이후 실행에 도움이 됩니다. 네이버가 세션을 만료하면 1번으로 다시 로그인하세요. 프로그램은 로그인 성공 여부를 자동 판별하지 않으므로 카페에서 직접 확인하세요. 비밀번호와 보안 인증은 네이버 화면에서 직접 입력합니다.

자동 접속은 https://cafe.naver.com/truckerking 을 즉시 열고 15초 뒤 닫으며, 창을 연 시점부터 30분 30초 간격으로 반복합니다. 종료 시 브라우저가 정보를 저장할 시간을 추가로 최대 3초 기다립니다. 중지는 콘솔에서 Ctrl+C입니다.

별도 Edge 프로필 `%LOCALAPPDATA%\CafeVisitorEdgeProfile`에 로그인 상태가 저장됩니다. 평소 Edge 프로필과는 별개이며, 인증정보는 GitHub에 업로드되지 않습니다. 로그인 중에는 이 전용 프로필로 연 다른 Edge 창도 함께 닫힐 수 있으므로 카페 용도로만 사용하세요.

PC가 켜져 있어야 합니다. 실제 방문수 반영은 보장되지 않습니다. Windows에서 실제 로그인·실행 검증은 수행하지 않았습니다.

BAT에는 함께 제공되는 `cafe-visitor.ps1` 소스가 포함되어 있으며 PowerShell로 실행합니다. 조직에서 PowerShell 실행을 제한한 경우 관리자에게 문의하세요.

## 반복 실행 확인

1번으로 로그인했다면 콘솔로 돌아와 Enter를 눌러야 자동 반복이 시작됩니다. 로그인 창에서 Enter를 누르는 것과 다릅니다. 3번은 로그인만 하고 종료합니다.

자동 반복이 시작되면 접속 시도 번호, 다음 접속 예정 시각, 남은 시간이 표시됩니다. 검은 콘솔 창을 닫거나 PC가 절전 상태가 되면 실행할 수 없습니다. 각 접속 시도 중 오류는 화면과 로그 파일에 기록하고 다음 예정 시각에 재시도합니다. 로그의 브라우저 열기 완료는 페이지 로딩이나 방문수 반영을 증명하지 않습니다.

## 실행 로그

실행 파일과 같은 폴더에 `cafe-visitor.log`가 생성됩니다. 해당 폴더에 쓸 수 없으면 `%LOCALAPPDATA%\CafeVisitor\activity.log`에 저장합니다. 실제 저장 위치는 검은 창에 표시됩니다.

시작·로그인 대기·접속 시도 번호·브라우저 실행 명령·Edge 창 확인 결과·창 닫기·다음 접속 시각·오류·정상 종료를 시각과 함께 누적 기록합니다. 강제 종료나 전원 차단 시 종료 기록은 남지 않을 수 있습니다. 브라우저 창 확인은 네이버 페이지 로딩이나 방문수 집계 성공을 뜻하지 않습니다.

재접속이 안 되면 `cafe-visitor.log`의 마지막 20줄을 확인하거나 공유하세요. 비밀번호·쿠키·로그인 입력값은 수집하지 않습니다.
