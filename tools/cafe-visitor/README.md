# 카페 자동 접속 도구 (Windows 10)

Microsoft Edge가 필요합니다. `cafe-visitor.bat`을 다운로드하고 더블클릭하세요.
즉시 https://cafe.naver.com/truckerking 을 열고 15초 후 닫으며,
창을 연 시점부터 30분 30초 간격으로 반복합니다. 중지는 콘솔에서 Ctrl+C입니다.

별도 Edge 프로필을 사용합니다. PC가 켜져 있어야 하며 실제 방문수 반영은 보장되지 않습니다.
Windows 실행 검증은 수행하지 않았습니다.

BAT에는 함께 제공되는 PowerShell 소스를 UTF-16LE Base64로 인코딩한 내용이 들어 있습니다.
비밀번호나 인증정보는 포함되지 않습니다. 조직의 실행 정책을 우회하지 않습니다.
